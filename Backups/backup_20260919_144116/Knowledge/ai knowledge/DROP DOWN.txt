Define the Sovereign's Toolset: Give the Sovereign the call_manager tool. This tool sends your intent (e.g., "Optimize the 3rd gear drift physics for the 2019 WRX") to the Manager.

<details>
<summary><strong>Step 2: The Manager Logic & Routing</strong></summary>
Once the Manager receives the intent, it uses Pydantic AI to validate and route the request to the correct groups.
Parsing: The Manager identifies if the task is Physics (Group 2), Visuals (Group 3), or Assets (Group 1).
Group Dispatch:
Pilot Agent gets the torque curves.
Pacejka Analyst fetches real-world slip data.
Inspector stands by to monitor draw calls.
Cross-Agent Sync: The Manager ensures the Maestro (Audio) receives the speed data from the Pilot so the engine roar matches the actual physics.
</details>
<details>
<summary><strong>Step 3: Executing Native AI Changes (Unreal & Blender)</strong></summary>
This is where the agents physically touch your project files using the MCP Bridge.
Unreal Engine 5.7.3 Interaction:
The Forge Agent uses the unreal-engine-mcp server to run Python scripts inside the UE Editor.
It can automatically adjust Chaos Vehicle parameters or swap materials on the fly.
Blender 2026 Interaction:
If a mesh needs a "Damage Mask" update, the Librarian triggers a Blender script via the blender-mcp server.
The Material Scientist agent feeds the specific $\mu$ (friction) values directly into the Blender shader nodes before exporting back to Unreal.
</details>
<details>
<summary><strong>Step 4: The Validation & Feedback Loop (Layer 4 & 5)</strong></summary>
Before any change is "committed," the system checks for safety.
Pydantic Guard: If the Pilot tries to set a torque value that would break the physics engine, the Pydantic validator returns a "Value Out of Range" error to the Manager.
The n8n State Machine:
Success: The agent logs the change and notifies the Sovereign.
Failure: The loop triggers a "Self-Correction." The Manager asks the Inspector to re-analyze the script and try a different approach.
Escalation: If it fails 3 times, it pings you in VS Code for manual intervention.
</details>
