Why the Restart is Non-Negotiable
When you enable the Remote Control API, Unreal Engine needs to initialize a Web Server (typically on port 30010) that runs in the background of the editor process.
Initialization: The server hooks into the engine's core memory and the Reflection System. A restart is required to ensure that the server starts alongside the engine, allowing it to "register" all the actors, properties, and Python scripts in your current project.
The "Talking" Mechanism: Without this server active, your VS Code agent is essentially shouting into a void. Once active, the agent "talks" to Unreal via HTTP PUT/POST requests. It sends JSON payloads (data packets) that say things like, "Hey Unreal, change the 'Intensity' of 'DirectionalLight_0' to 5000."

The "Self-Correction" Architecture
In a production-ready environment, you don't just notify the human when something goes wrong; you first empower the agent to attempt a fix. We will use the Orchestrator-Worker-Validator pattern.

1. The Strategy: Automated Reflection
Instead of a single line of execution, we create a loop in n8n that follows this logic:
Step 1: The Worker Agent (Blender) generates the script.
Step 2: The Validator (Pydantic) checks the vertex_count.
Step 3: If vertex_count > 5000, the system automatically sends the error back to the Worker with the specific instruction: "Your mesh has X vertices, which exceeds the 5,000 limit. Regenerate using a Decimate modifier or lower subdivision level."
Step 4: Only after 3 failed attempts (or a successful fix) is the Notification Agent (Slack/Email) triggered to alert you.

2. The Implementation: Pydantic Validation Constraints
You set the specific rule inside the Field definition of your Pydantic model. This acts as the "Gatekeeper" that prevents "AI slop" from entering your Unreal project.

3. Why This Saves Performance
Resource Management: By rejecting the asset before export, you save the CPU/GPU time required for Blender to render/export a heavy FBX and for Unreal to import it.
Project Integrity: Your Unreal scene stays performant. You avoid the "FPS death" that occurs when "un-optimized" AI assets clutter your landscape.
Personal OS: As outlined in the 2026 standards, this approach embodies your technical requirements into Markdown (.md) files that the agent treats as its "Laws".
